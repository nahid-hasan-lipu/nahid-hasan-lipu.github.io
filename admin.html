Photo Admin

Paste a GitHub personal access token (scoped to just this repo's contents) to manage the site's photos.

Create one at github.com → Settings → Developer settings → Fine-grained tokens → Generate new token. Under "Repository access," select only nahid-hasan-lipu.github.io. Under "Permissions," set Contents to Read and write — leave everything else as No access. The token is saved only in this browser (localStorage), never sent anywhere but GitHub's own API.
